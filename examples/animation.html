Animation

Formulas are laid out once with layoutTeX; every frame only calls render under a new transform. Rotation, scaling and colour come from the context, the glyphs stay sharp. 

const box = await layoutTeX(katex, tex, ctx, { fontSize: 22 });
function frame(t) {
    ctx.save();
    ctx.translate(x, y);
    ctx.rotate(angle(t));
    ctx.scale(s, s);
    render(ctx, box, 0, 0, { align: "center", baseline: "middle" });
    ctx.restore();
    requestAnimationFrame(frame);
}
