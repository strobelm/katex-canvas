KaTeX formulas, drawn on a canvas

katex-canvas lays out KaTeX's output and draws it with the 2D canvas API: vector glyphs and paths that follow the context's transform, in workers too. The layout reproduces KaTeX's HTML rendering; in Chromium it is checked pixel by pixel against it for several hundred formulas. 

npm install katex-canvas katex
import katex from "katex";
import { drawTeX } from "katex-canvas";
import "katex/dist/katex.css"; // KaTeX's fonts

const ctx = canvas.getContext("2d");
await drawTeX(katex, ctx, "\\int_0^\\infty e^{-x^2}\\,dx = \\frac{\\sqrt\\pi}{2}", 200, 100, {
    fontSize: 28,
    align: "center",
});
