Worker

The canvas is handed to a web worker with transferControlToOffscreen. The worker has no DOM and no stylesheet: it registers KaTeX's fonts with registerKatexFonts and draws with drawTeX. The main thread stays free, try typing while it redraws. 

// worker
import katex from "katex";
import { drawTeX, registerKatexFonts } from "katex-canvas";

registerKatexFonts("https://cdn.jsdelivr.net/npm/katex@0.19.0/dist/fonts/");
self.onmessage = async ({ data }) => {
    if (data.canvas) ctx = data.canvas.getContext("2d");
    ...
    await drawTeX(katex, ctx, data.tex, width / 2, height / 2, { fontSize: 30, align: "center", baseline: "middle" });
};
